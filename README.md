# 📊 Data Professional Survey Dashboard (Power BI)

## 🧠 About the Project
This project is a Power BI dashboard built to explore and understand trends in the data professional community. The goal was to analyze survey data and turn it into meaningful insights that can help understand salaries, job roles, skills, and overall satisfaction levels.

Instead of just showing raw data, I focused on creating a dashboard that clearly answers real questions like:
- Which roles earn more?
- What skills are most popular?
- How satisfied are people with their jobs?

---

## 🎯 Key Insights

- **Average Age** of survey participants is around **29.87 years**
- Total number of respondents: **630**
- **Data Scientists** appear to have higher average salaries compared to other roles
- **Python** is the most popular programming language among respondents
- Work-life balance satisfaction is relatively good (**5.74 / 10**)
- Salary satisfaction is lower (**4.27 / 10**), showing a gap between expectations and reality
- Salary varies significantly based on **education level and job role**

---

## 📊 Dashboard Features

- 📈 Salary comparison across different job roles
